## 🎯 核心定位
- **拒绝**商务 / 财务 / 专业英语，拒绝四六级应试刷题

## 🧭 学习方法论
1. **素材选择**：只选海外普通人 Vlog、生活类英文博主、旅行短片、小红书生活化英文手帐 / 英文 Vlog 博主；不用教材课文、应试阅读。
2. **核心原则**：优先积累完整句型 ＞ 孤立背单词；**输入必须配套输出**。
3. **每日结构（30–60 分钟，可碎片拆分）**
   - ① **输入（15–25min）**：盲听短视频 → 对照字幕抓短句 → 只摘抄可立即复用的句子，不整段复制
   - ② **改写内化（10–15min）**：结合真实生活改写 → 录入句型金库 → 同步写进当日手帐
   - ③ **口语输出（10–20min）**：只写关键词提纲，录音口述；**禁止逐字稿朗读**；复盘卡顿词汇
