🧭 学习方法

🎯 核心定位

拒绝商务 / 财务 / 应试英语，只聚焦 日常起居 · 内心感悟 · 旅行场景 · 社交闲聊。目标：把"想法"直接组织成英文短句，摆脱脑中中译英。

✅ 学习范围（严格剔除商务/财务）

纳入：作息饮食、运动情绪、时间管理、手帐文案、反思治愈、旅行衣食住问路、爱好观影逛街。

排除：财务报表、商务会议、邮件谈判、行业术语、学术长文、四六级阅读题型。

🔄 每日学习结构（30–60分钟，可拆碎片）

① 输入 15–25min盲听短视频 → 抓可复用短句
② 改写内化 10–15min结合生活改写 → 录进句型库
③ 口语输出 10–20min只写关键词提纲 → 录音口述
💡 加速版说"来一段影子跟读" → 我陪练

🗣️ 影子跟读法（快速开口）

来源：@Kyson英语重启 笔记 #影子跟读。听一句生活化英文 → 几乎同步跟读 → 练口腔肌肉+语感+反应速度，不先背单词。

AI 陪练脚本：我选 ≤40 秒素材 → 给原文+中文+卡点提示 → 你盲听1遍 → 跟读3轮 → 录1轮 → 发卡点我反馈 → 金句入库。
