# 🌿 生活化英语成长工作台

手帐 · 日常 · 旅行 · 社交 —— 90 天开口计划。

**在线使用**：开启 GitHub Pages 后访问 `https://<用户名>.github.io/<仓库名>/`

## 这是什么

一个零依赖的单文件网页 App，专注**生活化英语**（不含商务/金融/考试内容），面向大学六级水平、被动词汇够但主动调取难、习惯中译英的学习者。

## 功能

| 模块 | 说明 |
|---|---|
| 📅 今日 | 打卡（输入/口语/跟读/手帐）、今日一句、我的档案、素材推送 |
| 📖 素材库 | 小红书博主关键词收纳，按场景分类 |
| 📝 句型库 | 核心模块，记录 + 复习标记 |
| 🗣️ 跟读 | 20 句生活化素材，内置离线 TTS 发音，支持 0.7x / 1.0x 变速 |
| 🎙️ 口语 | 口语练习日志，可本地录音自比（不上传） |
| 🔍 复盘 | 每周目标 + 复盘表单 |
| 🧭 方法 | 影子跟读法、每日结构、90 天三阶段、数据备份 |

## 隐私

所有数据（打卡记录、句型库、口语日志、个人档案）**只保存在你自己浏览器的 localStorage 里**，不会上传到任何服务器。仓库里没有任何个人数据。

换设备前请到「🧭 方法 → ⚙️ 数据管理 → 📤 导出备份」保存一份，在新设备用「📥 导入备份」恢复。

## 手机使用建议

在浏览器打开链接后：
- **iPhone**：Safari → 分享 → 添加到主屏幕
- **Android**：Chrome → 菜单 → 添加到主屏幕

之后就像一个原生 App 一样从桌面图标打开，离线也能用。
